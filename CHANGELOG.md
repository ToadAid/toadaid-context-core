# Changelog

This project is currently alpha. Until the first stable release, this changelog records major public-contract milestones rather than promising semantic-versioning stability.

## Unreleased

### Public release hardening

- Added the repository's open-source foundation: license, security policy, contribution guide, code of conduct, and public package metadata.
- The npm package remains marked `private` while public source readiness is completed.

## Current alpha baseline — `0.1.0-alpha.1`

The current alpha includes:

- exact-evidence preservation and bounded context diversion;
- structure-aware deterministic chunking;
- explainable tiered lexical recall;
- persistent retrieval with integrity-bound acceleration and candidate-bounded execution;
- proof-carrying ingress/retrieval telemetry and honest byte accounting;
- deterministic retrieval-quality evaluation;
- restart-safe session journals, resume packets, omission recovery, and bounded continuity transport;
- provider-neutral tool-output ingress with live host adoption;
- a zero-authority capability boundary for model, network, shell, wallet, trade, git-write, durable-memory-write, and authority-grant actions.

See [BUILD_LIST.md](BUILD_LIST.md) for the detailed capability history.
